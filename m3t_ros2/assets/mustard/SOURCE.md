# YCB mustard bottle mesh

`model.obj` is the Google 16k geometry for YCB object `006_mustard_bottle`, downloaded from `https://ycb-benchmarks.s3.amazonaws.com/data/google/006_mustard_bottle_google_16k.tgz`.

The original 9 MB texture map is not required by M3T and is not packaged. `textured.mtl` supplies a local solid mustard color so the OBJ has no missing runtime asset.
